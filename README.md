# Price transmission replication materials

This repository contains code and generated outputs for two computational exercises in asymmetric price transmission. It does not contain a manuscript or research microdata.

## What this repository reproduces

The first exercise recalculates a finite-horizon price-wedge exposure from the adjustment coefficients and horizons reported in Abdulai (2000). The output is normalized by baseline volume times the absolute initial log deviation. It is a volume-weighted log-wedge exposure, not a household expenditure share, consumer-surplus estimate, or food-security outcome.

The second exercise simulates symmetric adjustment, speed asymmetry, and regime-dependent long-run slopes at sample sizes of 120 and 240. Each of the six design cells uses 1,000 replications. The fitted single-vector AECM tests equality of the positive and negative adjustment coefficients using a two-sided Newey-West HAC Wald statistic with lag four.

The magnitude-asymmetry design deliberately violates the fitted single-vector long-run relation. Its rejection frequency is therefore not a valid test of slope asymmetry and is not presented as a general misclassification probability.

The simulation draws are generated by the script. They are methodological data only and are not empirical observations or substitutes for market or household microdata.

## What is outside the scope

This release does not reproduce the Nigerian FEWS NET market estimates, the pooled market result, the market-level power analysis, or the five-pair ratchet diagnostic. Those analyses require the source price file and the associated empirical pipeline. The source file is not included here. No household microdata were used in these two computational exercises.

The release also excludes the private literature workbook, its extracts and annotations, internal synthesis documents, unpublished manuscripts, and processing outputs from other projects.

## Requirements

Python 3.10 or later and NumPy are required. The script uses a fixed random seed so the simulation can be regenerated. Numerical values can vary slightly across Python and NumPy versions.

Install the dependency from the repository root.

```bash
python -m pip install -r requirements.txt
```

Regenerate the two JSON files in `outputs/`.

```bash
python src/replicate.py
```

To write results to another directory, pass `--output-dir PATH`.

## Data and source

The calibration uses coefficients and adjustment horizons reported in the published study below. It does not require a downloaded dataset.

Abdulai, A. (2000). Spatial price transmission and asymmetry in the Ghanaian maize market. *Journal of Development Economics*, 63(2), 327–349.

The Monte Carlo uses only parameters stated in the script. No external empirical file is read by the program.

## Files

- `src/replicate.py` contains the calculations and simulation.
- `outputs/abdulai_calibration.json` contains the finite-horizon calibration.
- `outputs/single_vector_monte_carlo.json` contains the six simulation results.
- `requirements.txt` records the sole third-party Python dependency.

## Interpretation

The exposure calculation is a first-order, constant-volume price-wedge benchmark. Mapping it to household welfare requires additional household-level information and behavioral assumptions. The simulation describes the behavior of the specified estimator under the stated designs. It does not establish the prevalence or welfare effect of asymmetric transmission in observed markets.
